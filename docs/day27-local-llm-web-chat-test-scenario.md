# День 27 — сценарий проверки (локальный веб-чат)

Предусловия: Ollama запущена (`curl localhost:11434` → `Ollama is running`), модели `gemma4:26b-a4b-it-qat` и `gemma4:31b-mlx` скачаны, `./gradlew :web-console:run`.

1. Открыть `http://localhost:8080`, вкладка **Local LLM**. Ожидание: в списке обе модели, статус `Ollama @ http://localhost:11434 · 2 model(s)`.
2. Спросить «Столица Австралии? Ответь одним словом.». Ожидание: «Канберра», под ответом модель, токены, tok/s, время.
3. Отправить 2–3 сообщения подряд с включённой историей («Меня зовут Анна» → «Как меня зовут?»). Ожидание: модель помнит имя; после снятия «send conversation history» — нет.
4. Включить **compare models**, отметить обе модели, спросить «Объясни прогрессивную перегрузку в трёх предложениях». Ожидание: две колонки, у `gemma4:26b-…` заметно выше tok/s.
5. Переключатель **thinking**: off/on/default на задаче про три выключателя. Ожидание: при `on` под ответом блок «thinking (N chars)».
6. Остановить Ollama (`brew services stop ollama`), отправить сообщение. Ожидание: ошибка «Local model call failed…», в истории сообщение не сохраняется; на вкладке предупреждение с подсказкой запуска.
7. Автотесты: `./gradlew :core:llm:test :web-console:test` — зелёные.

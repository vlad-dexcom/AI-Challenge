# День 26 — локальная LLM (Ollama)

Цель: установить и запустить локальную LLM, проверить доступ через CLI и HTTP API, сделать запросы разной сложности. Код приложения не менялся.

## Окружение и выбор модели
- Mac Apple Silicon (arm64), 36 ГБ RAM, Ollama **0.35.1** (`brew install ollama`, сервис `brew services start ollama`, порт `11434`).
- Модель: **qwen2.5:7b** (7.6B параметров, Q4_K_M, GGUF, 4.7 ГБ, контекст 32768). Хорошо знает русский, умеет код, комфортно помещается в память (запасной вариант — `llama3.2:3b`).
- Параметры: по умолчанию (temperature/top_p из Modelfile), `stream=false` для HTTP. Ollama в brew-сервисе стартует с `OLLAMA_FLASH_ATTENTION=1`, `OLLAMA_KV_CACHE_TYPE=q8_0`.

## Проверки
| Проверка | Результат |
|---|---|
| `ollama pull qwen2.5:7b`, `ollama list` | модель в списке, 4.7 ГБ |
| `curl localhost:11434/` | `Ollama is running` |
| CLI `ollama run … --verbose` | ответ получен |
| HTTP `/api/tags`, `/api/generate`, `/api/chat` | работают, ответы JSON |

## Три запроса
Скорость = `eval_count / eval_duration`.

| # | Сложность | Канал | Токенов (prompt/ответ) | Время | Скорость |
|---|---|---|---|---|---|
| 1 | простой: «Столица Франции?» | CLI (первый запуск, загрузка модели 3.0 с) и `/api/generate` | 45/13 (CLI), 45/14 (HTTP) | 4.0 с (с загрузкой), 0.7 с (прогретая) | 25.9 / 25.0 tok/s |
| 2 | средний: функция `reverseString` на Kotlin без `reversed()` | `/api/chat` | 63/237 | 10.6 с | 23.1 tok/s |
| 3 | сложный: недельный план тренировок (3 силовых дня, травма колена, гантели+петли, ≤40 мин, разминка, прогрессия, таблица) | `/api/chat` | 127/700 | 29.8 с | 23.9 tok/s |

Ответы: полные тексты — в [тест-сценарии](day26-local-llm-test-scenario.md).

## Оценка качества
1. «Столица Франции - Париж.» — верно.
2. Код корректен (StringBuilder + `downTo`), объяснение по делу.
3. Формат (таблица, примечания) соблюдён, но **содержание слабое**: 5 тренировочных дней вместо 3, упражнения неточные («подъемы на наклонную скамейку» без скамейки, «жим стоя» назван упражнением на ноги), нет конкретной прогрессии по неделям. Ограничения «без глубоких приседаний» и «≤40 мин» формально соблюдены.

## Выводы
- Локальная модель запускается и отвечает через CLI и HTTP; ~23–26 tok/s на 7B Q4 — достаточно для интерактива.
- Первый запрос дороже на загрузку модели (~3 с); дальше модель в памяти (по умолчанию выгружается через 5 мин простоя).
- На многоограничительных задачах 7B ошибается в ограничениях — для задач приложения (тренировочные планы) понадобятся проверка/RAG или модель побольше.
- Задел: с Android-эмулятора Ollama доступна по `http://10.0.2.2:11434`; для устройства по LAN нужен `OLLAMA_HOST=0.0.0.0`.

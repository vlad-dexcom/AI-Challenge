# Local model performance

In Local mode the answers are generated by a model that runs on the owner's Mac (Ollama). Speed depends on that machine, not on the phone.

- **The first answer is slow** (tens of seconds): the model is loaded into memory on the first request after it was idle. Run `scripts/private-ai.sh warmup` to load it in advance.
- **Every answer is slow**: another heavy program is using the GPU or memory (for example a benchmark or a second model), or the context window is large. Close other models and check `ollama ps`.
- **Long conversations get slower**: the whole history is sent each time. Start a new chat.
- **The answer stops in the middle**: the token limit of the gateway was reached; use the "Continue" button.
- **Answers are worse than in Cloud mode**: the local model is smaller. This is expected; for quality-critical questions use Cloud mode.
- **The phone shows no streaming text**: the Wi-Fi connection to the Mac dropped. Check that both devices are on the same network and the gateway page still opens.

Local mode needs no internet and no Gemini key, but it needs the Mac to be awake and the gateway to be running.
